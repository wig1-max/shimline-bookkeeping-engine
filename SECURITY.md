# Security policy

This repository is an archived research prototype. Please do not open public
issues containing credentials, client financial data, bank records, invoices,
or details that would make an active deployment easier to attack.

For a vulnerability in the published code, use GitHub's private vulnerability
reporting feature if it is enabled for the repository. If it is not available,
contact the repository owner privately through the email address on the GitHub
profile. Include the affected file, a minimal reproduction, impact, and any
suggested mitigation.

This project has no hosted service, no production support commitment, and no
security bounty program.
