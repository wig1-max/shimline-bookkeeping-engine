# Contributing

Contributions that improve reproducibility, evidence handling, deterministic
controls, fixture quality, or documentation are welcome.

Before opening a pull request:

1. Do not add customer, bank, invoice, credential, or production data.
2. Keep financial calculations deterministic and covered by tests.
3. Cite authoritative sources for legal or tax assertions; do not paste
   proprietary professional guidance into the repository.
4. Preserve the safety boundary: a model may rank bounded choices, but it does
   not invent accounting facts or directly execute a write.
5. Run the relevant test suite and describe the observable behaviour changed.

Apache License, Version 2.0.
